# Moru Studio

前台商店和管理后台都在这个文件夹里：根目录是前台，`admin/` 是后台。

## 打开网站

双击 `启动网站.command`，浏览器会自动打开后台：

`http://127.0.0.1:8787/admin/#/products`

商店前台地址：

`http://127.0.0.1:8787/index.html`

也可以在当前目录运行：

```bash
npm start
```

`server.py` 同时提供前台和后台：根路径读取前台文件，`/admin/` 读取 `admin/` 文件夹，商品数据保存在 `admin/data/products.json`，前后台共用同一份数据。

## 已支持

- 前后台共用商品数据
- 商品列表
- 新建、编辑商品
- 上传并预览商品图片
- 商品上架与下架
- 电脑与手机尺寸适配

在后台下架商品后，该商品会从前台隐藏；重新上架后会恢复。打开着的前台标签页会在商品变动后自动刷新。
